Port Security Lab

A switch port locked to a single, automatically-learned MAC address — with a deliberate violation test to confirm the port shuts itself down when an unauthorized device connects.

Port Security Sticky MAC Cisco IOS
01

Topology

PC1 ─── SW1 ─── PC2 Fa0/1 Fa0/2
02

Configure Ports

interface fa0/1
 switchport mode access
 no shutdown
exit
interface fa0/2
 switchport mode access
 no shutdown
exit

Note: PC-facing ports are configured as access ports.

03

Enable Port Security

interface fa0/1
 switchport port-security
 switchport port-security maximum 1
 switchport port-security violation shutdown

Note: Only one MAC address is allowed on this port. An unauthorized MAC address triggers a shutdown.

04

Enable Sticky MAC

switchport port-security mac-address sticky

Note: The switch automatically learns and saves the connected PC's MAC address as the allowed one.

05

Verify

show port-security interface fa0/1
FieldValue
Port SecurityEnabled
Port StatusSecure-up
Maximum MAC Addresses1
Sticky MAC Addresses1
Security Violation Count0
06

Test a Violation

Connected a different PC to Fa0/1 — its MAC address doesn't match the sticky-learned MAC, so the port should shut down.

Result: Secure-shutdown

07

Recover the Port

interface fa0/1
 shutdown
 no shutdown

Reconnect the authorized PC afterward.

08

Key Commands to Remember

  • switchport port-security — enable port security on the interface
  • switchport port-security maximum 1 — allow only one learned MAC
  • switchport port-security mac-address sticky — auto-learn and save the MAC
  • switchport port-security violation shutdown — err-disable the port on a violation
  • show port-security interface fa0/1 — check status, violation count, learned MAC

Main idea: Port security controls which devices are allowed to connect to a switch port.
