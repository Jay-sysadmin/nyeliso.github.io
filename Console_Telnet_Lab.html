// Networking Lab

Console Line & Telnet

Configured two different methods for accessing and managing a Cisco router — direct physical access via console line and remote network access via Telnet VTY lines. Includes password protection for both console and privileged EXEC modes.

Cisco Packet Tracer Cisco IOS CLI Console Access VTY Lines Remote Management
01 // Objective
Learn two methods of router access: Console Line for direct physical management and Telnet via VTY Lines for remote network-based management. Configure passwords for both to protect router access.
02 // Topology
  [ Laptop ]                         [ PC ]
      |                                 |
 Console Cable              Network cable
      |                                 |
  [ Router ] ─────── Switch ───────────┘
  G0/0: 192.168.1.1

  Laptop (Console): 192.168.1.20 / GW: 192.168.1.1
  PC (Telnet):      192.168.1.10 / GW: 192.168.1.1
03 // Part 1 — Console Line
Direct Physical Access
Configure console password
line console 0
! Selects the router console connection
password cisco123
! Sets the console access password
login
! Forces router to prompt for the password
Configure enable secret (privileged mode)
enable secret admin123
! Protects privileged EXEC mode (#)
! Required after login to get full access
04 // Part 2 — Router IP & PC Setup
Configure router interface
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

05 // Part 3 — Telnet via VTY Lines
Remote Network Access
Configure VTY lines for Telnet
line vty 0 4
! Opens VTY lines 0–4 (5 simultaneous remote sessions)
password telnet123
! Sets the Telnet login password
login
! Forces password prompt on remote login
transport input telnet
! Allows Telnet connections on these lines
PC — Connect via Telnet
Desktop → Command Prompt
telnet 192.168.1.1
Password: telnet123
Router> enable
Password: admin123
Router#  ← Full privileged access
