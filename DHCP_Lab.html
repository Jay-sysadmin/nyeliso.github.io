DHCP Server Configuration

Configured a Cisco router to act as a DHCP server — automatically assigning IP addresses, subnet masks, default gateways, and DNS servers to client PCs on the 192.168.2.0/24 network. No manual PC configuration needed.

Cisco Packet Tracer Cisco IOS CLI Router 2911 Switch 2960 DHCP
01 // Objective
Configure the router interface as the DHCP server for the 192.168.2.0/24 network. Exclude reserved addresses, define a DHCP pool named OFFICE, set the default gateway and DNS server, then verify automatic IP assignment on client PCs.
02 // Topology
     [ Router 2911 ]
     G0/0: 192.168.2.1
     DHCP Server + Gateway
           |
    (Straight-Through)
           |
     [ Switch 2960 ]
      /    |        PC1   PC2   PC3
   DHCP  DHCP  DHCP
  .11    .12   .13
03 // Configuration
Step 1 — Configure Router Interface
interface g0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
! Creates the 192.168.2.0/24 network
! Sets router IP to 192.168.2.1 — acts as gateway
! Enables the interface
Step 2 — Exclude Reserved Addresses
ip dhcp excluded-address 192.168.2.1 192.168.2.10
! Reserves .1 to .10 for router, servers, printers
! DHCP will only assign .11 and above
Steps 3–6 — Create DHCP Pool
ip dhcp pool OFFICE
! Creates pool named OFFICE
network 192.168.2.0 255.255.255.0
! Defines the network DHCP manages
default-router 192.168.2.1
! Gives clients the gateway IP
dns-server 8.8.8.8
! Gives clients Google DNS for name resolution
04 // PC Setup & Verification
PC — Set to DHCP
Desktop → IP Configuration → DHCP
PC automatically receives:
  IP Address:      192.168.2.11
  Subnet Mask:     255.255.255.0
  Default Gateway: 192.168.2.1
  DNS Server:      8.8.8.8
Router — Verification Commands
show ip dhcp binding    Shows leased IPs
show ip dhcp pool       Shows pool info
show ip interface brief Confirms interface up

PC Command Prompt:
ipconfig               Shows assigned config
ping 192.168.2.1       Tests gateway connectivity
