EtherChannel / LACP Lab

Two redundant switch-to-switch links bundled into a single logical port-channel using LACP — more bandwidth, redundancy, and a link topology that Spanning Tree Protocol sees as one path instead of a loop.

EtherChannel LACP Port-Channel Cisco IOS

02

Configure LACP

SW1 & SW2
interface range fa0/23 - 24
 channel-group 1 mode active
exit

Note: active enables LACP negotiation between the two switches.

04

What We Learned

EtherChannel combines multiple physical links into one logical link.

Before — two separate links SW1 ─── SW2
SW1 ─── SW2
After — one logical link SW1 ══ SW2
   Po1
  • More bandwidth — traffic load-balances across bundled links
  • Redundancy — if one physical link fails, the bundle keeps forwarding
  • Better link utilization than leaving redundant links idle
  • STP sees the bundle as a single logical link, not a loop

Main takeaway: LACP combines multiple physical switch links into one logical EtherChannel. Main command to remember: channel-group 1 mode active

05

Commands to Remember

  • interface range fa0/23 - 24 — select multiple interfaces at once
  • channel-group 1 mode active — add interfaces to Port-Channel 1 using LACP active mode
  • show etherchannel summary — verify bundle status and member ports
