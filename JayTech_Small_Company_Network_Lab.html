JayTech Small Company Network

A small company network simulation with an IT department, HR department, and a branch office — built to practice VLAN segmentation, router-on-a-stick inter-VLAN routing, static routing to a remote branch, and end-to-end connectivity testing.

VLANs Inter-VLAN Routing Router-on-a-Stick Static Routing Network Troubleshooting
01

Project Overview

This project simulates a small company's network with an IT department, HR department, and a branch network. The lab was designed to practice:

  • IPv4 addressing
  • VLAN configuration
  • Access ports
  • Trunking
  • Router-on-a-stick
  • Inter-VLAN routing
  • Static routing
  • Network connectivity testing
  • Basic Cisco troubleshooting

05

R1 — Router-on-a-Stick Configuration

R1 uses subinterfaces to provide gateways for both VLANs over a single trunked physical link.

interface gigabitEthernet 0/0
 no shutdown
exit
interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
exit
interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
exit
interface gigabitEthernet 0/1
 ip address 10.0.0.1 255.255.255.252
 no shutdown
exit
end

Check: show ip interface brief — expected: G0/0.10 → 192.168.10.1, G0/0.20 → 192.168.20.1, G0/1 → 10.0.0.1

Static Routes

R1 — needs a route to the branch network
ip route 192.168.40.0 255.255.255.0 10.0.0.2
end
R2 — needs routes to the two company VLANs
ip route 192.168.10.0 255.255.255.0 10.0.0.1
ip route 192.168.20.0 255.255.255.0 10.0.0.1
end

Check: show ip route on both routers

Testing Commands

  • show ip interface brief — check router interfaces
  • show vlan brief — check VLANs
  • show interfaces trunk — check trunk status
  • show ip route — check the routing table
  • ping 10.0.0.2 (on R1) — test R1 → R2
  • ping 10.0.0.1 (on R2) — test R2 → R1
  • ping 192.168.10.1 (PC1), ping 192.168.20.1 (PC3), ping 192.168.40.1 (PC4) — test PC → gateway
  • ping 192.168.20.10 (from PC1) — test inter-VLAN routing
  • ping 192.168.40.10 (from PC1) — test branch connectivity
