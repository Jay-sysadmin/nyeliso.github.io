VLANs & Router-on-a-Stick

Configured VLANs on a Cisco switch to separate Students and Staff into logical networks, then used Router-on-a-Stick with 802.1Q subinterfaces to enable controlled communication between VLANs through a single router interface.

Cisco Packet Tracer Cisco IOS CLI 802.1Q Trunking Router 2911 · Switch 2960 VLANs
01 // Objective
Create two VLANs (Students and Staff) on one physical switch, configure a trunk link to the router, then enable inter-VLAN routing using Router-on-a-Stick subinterfaces — so departments can communicate while remaining logically separated at Layer 2.
02 // Topology

          G0/0.10 → 192.168.10.1  (Students gateway)
          G0/0.20 → 192.168.20.1  (Staff gateway)

03 // Switch Configuration
Create named VLANs
vlan 10
name STUDENTS
vlan 20
name STAFF
Assign access ports to VLANs
interface fa0/1
switchport mode access
switchport access vlan 10

interface fa0/2
switchport mode access
switchport access vlan 20
Configure trunk port to router
interface fa0/24
switchport mode trunk
! 802.1Q carries both VLAN 10 and VLAN 20 traffic to router
04 // Router Configuration
Enable physical interface + configure subinterfaces
interface g0/0
no shutdown

! VLAN 10 — Students
interface g0/0.10
encapsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0

! VLAN 20 — Staff
interface g0/0.20
encapsulation dot1Q 20
ip address 192.168.20.1 255.255.255.0
05 // Key Concepts
ConceptWhat It Does
VLANSeparates one switch into multiple logical networks
Access PortConnects an end device to one specific VLAN
Trunk PortCarries multiple VLANs over one cable (802.1Q tagged)
802.1QProtocol that tags frames with VLAN IDs
SubinterfaceVirtual router interface mapped to a specific VLAN
Router-on-a-StickOne physical router port routing between multiple VLANs
GatewayRouter address used by PCs to leave their VLAN
