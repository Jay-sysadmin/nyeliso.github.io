Networking — Cisco Packet Tracer

Spanning Tree Protocol Lab

Two switches connected by redundant links — configured a root bridge and observed STP automatically block one path to prevent a Layer 2 loop while keeping the second link as a live backup.

STP Root Bridge Loop Prevention Cisco IOS
01

Topology

PC1 PC2 │ │ Fa0 Fa0 │ │ Fa0/1 Fa0/1 SW1 SW2 │ Fa0/23 ───────────────── Fa0/23 │ │ Fa0/24 ───────────────── Fa0/24 │
Connections
PC1 Fa0 → SW1 Fa0/1
SW1 Fa0/23 → SW2 Fa0/23
SW1 Fa0/24 → SW2 Fa0/24
SW2 Fa0/1 → PC2 Fa0
02

Check Connections

show interfaces status

Note: Confirms all required ports are connected before checking STP behavior.

03

Check STP

show spanning-tree

Note: STP identifies redundant paths in the topology and prevents Layer 2 loops by blocking one of them.

04

Make SW1 the Root Bridge

enable
configure terminal
spanning-tree vlan 1 root primary

Note: SW1 becomes the preferred Root Bridge for VLAN 1.

05

Final Result

SwitchPortState
SW1Fa0/23Designated — Forwarding
SW1Fa0/24Designated — Forwarding
SW2Fa0/23Root — Forwarding
SW2Fa0/24Alternate — Blocking

Note: SW2 blocks Fa0/24 to prevent a Layer 2 loop, while keeping it available as a backup path if Fa0/23 fails.

06

Main Thing Learned

STP prevents Layer 2 loops and automatically fails over to the backup link if the active link goes down.

TermMeaning
